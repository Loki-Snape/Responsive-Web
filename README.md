# The Marauder's Map of Responsive Web Projects

> I solemnly swear that I am up to no good.

This repository is a curated collection of front-end practice projects built as a progression through HTML, CSS, and JavaScript. It is part study guide, part portfolio archive, and part wizarding map: every folder is a different spell, every project is a new lesson, and every finished page is another step toward stronger front-end craft.

The overall vibe is intentionally Harry Potter-inspired, but the work itself is real and practical. Each subproject focuses on a specific skill, UI pattern, or JavaScript challenge. Together they form a complete learning journey, moving from simple layout exercises to interactive utilities, data handling, and small app-like experiences.

## What This Repo Is

- A static front-end project collection.
- A learning log of HTML, CSS, and JavaScript exercises.
- A visual showcase of progression from beginner layouts to richer interactive builds.
- A theme-driven portfolio experience wrapped in a Harry Potter aesthetic.

## What This Repo Is Not

- It is not a framework app.
- It is not a backend service.
- It is not a build-tool-heavy codebase.
- It is not a single product with one user flow; it is a library of mini projects.

## Tech Stack

- HTML for structure and semantic content.
- CSS for layout, styling, and visual composition.
- JavaScript for interactivity, validation, calculations, and dynamic behavior.
- Vanilla front-end architecture, one folder per project.

## How To Use The Map

Open the root `index.html` in a browser and use it as a navigational hub. Each link opens a self-contained project. This makes the repository easy to explore, easy to teach from, and easy to compare across stages.

## Learning Progression

The folders are arranged like a curriculum arc.

- Sections 1.x to 2.x focus on foundations: semantic HTML, basic CSS, and visual structure.
- Sections 3.x to 5.x push harder into layout systems, composition, and more expressive styling.
- Sections 6.x to 9.x introduce JavaScript logic, DOM interaction, validation, calculations, and game mechanics.
- Sections 10.x to 11.x lean into richer thematic builds and more featureful mini applications.

## How The Projects Work As A Learning System

Every project plays a different role in the overall learning arc.

- Foundation projects teach how to structure content without getting lost in complexity.
- Visual projects teach how to make pages look intentional instead of default.
- Logic projects teach how to turn user input into meaningful output.
- App-style projects teach how to coordinate UI, state, and interaction.
- Theme-heavy projects teach how to build a strong identity without sacrificing readability.

## Design Language Of The Repo

The root experience uses a Harry Potter-inspired visual identity to make the collection feel memorable rather than generic.

- The map metaphor makes navigation feel like discovery.
- The chapter-style grouping gives the projects a narrative order.
- The fantasy tone adds personality while still preserving clarity.
- The overall presentation is meant to feel playful, ambitious, and a little dramatic in the best possible way.

## Suggested Workflow

1. Start at the root map and pick a project.
2. Open that folder's `index.html` in a browser.
3. Inspect the corresponding CSS and JavaScript files.
4. Modify one feature at a time so the learning stays visible.
5. Compare projects to see how complexity grows over time.

## Detailed Project Breakdown

### 1.1 Cat Pics

This project is a gentle first step into HTML structure. It presents simple cat-focused content with images and supporting text, which makes it useful for learning how to combine media, headings, paragraphs, and links into a readable page.

What I learned from it was how to organize content cleanly and how to make even a simple page feel complete. It also helped reinforce the idea that semantic HTML is the foundation of everything else that follows.

### 1.2 Menu

The menu project is about structuring food items in a clear, scannable layout. It usually depends on grouping items, prices, and descriptions in a way that feels balanced and easy to read.

From this project, I learned how spacing, alignment, and hierarchy change the way users experience information. It also built my confidence in using lists and layout rules to make content feel polished instead of plain.

### 1.3 Markers

Markers is a visual CSS exercise focused on color, gradients, and composition. The project recreates marker-like objects and gives practice with background styles, shape building, and careful use of borders and shadows.

What I learned here was that CSS can be used like a painting tool when the layers are planned well. I also learned how small styling details can completely change the realism and visual energy of a design.

### 1.4 Reg Form

The registration form project is about building a usable form interface that collects user data in a clear and friendly way. It usually includes inputs, labels, form groups, and validation-friendly structure.

This taught me how important accessibility and label association are in form design. It also helped me understand how form layout affects trust, usability, and the overall professionalism of a page.

### 2.1 Rothko Painting

This project recreates the layered feel of a Rothko-style abstract painting using only CSS. It is not about content; it is about shape, color, proportion, and the emotional effect of layering rectangles on a page.

I learned how far simple elements can go when positioning and color choices are deliberate. The project also sharpened my eye for composition and taught me to think of CSS as a visual design medium, not just a layout system.

### 2.2 Photo Gallery

The photo gallery project arranges multiple images into a responsive or flexible display. It focuses on how to show visual content without overwhelming the page, which makes it a strong exercise in spacing and grid-like thinking.

What I learned was how to present multiple media items consistently while keeping the layout balanced. It also improved my understanding of how responsive design decisions change the experience across different screen sizes.

### 2.3 Nutrient Label

This project recreates a nutrition facts label with very specific typography and spacing requirements. Its purpose is to teach precision, because every line, border, and indent matters when the design needs to feel real.

I learned how exact CSS can be when the design has to match a real-world reference. It also trained me to slow down and inspect details, especially in alignment, weight, and text structure.

### 2.4 HTML CSS Quiz

The quiz project presents question-and-answer content in a structured page format. It is useful for practicing semantic organization, readable spacing, and consistent visual grouping for longer blocks of information.

I learned how to keep content dense without making it feel cluttered. This project also reinforced how good hierarchy helps users move through large amounts of text without losing their place.

### 3.1 Balance Sheet

Balance Sheet turns financial information into a readable table-style layout. The main task is to make numbers, labels, and grouped categories easy to scan and compare without losing clarity.

I learned how useful strong alignment and consistent spacing are when presenting data. It also showed me how structure can make complex information look calm and understandable.

### 3.2 Cat Art

Cat Art is a CSS illustration exercise where shapes are combined to form a cat. It usually requires a strong understanding of positioning, stacking, pseudo-elements, and shape creation.

What I learned was that CSS art depends on patience and careful adjustment. It taught me how to break one visual idea into many small pieces and then layer them until the final figure appears.

### 3.3 Piano

The piano project is a visual interface that mimics a real keyboard. It focuses on building repeated keys, managing proportions, and keeping the layout visually recognizable.

I learned how repeatable UI patterns can be built with consistency and precision. It also helped me understand how small spacing errors can affect the realism of an interface.

### 4.1 Buildings

Buildings creates a skyline or city scene using CSS blocks and layered composition. The project is about repeating forms, scale, and the illusion of depth through stacking and placement.

I learned how to build larger scenes from smaller structural pieces. It also showed me that visual variety can come from simple shapes if the arrangement is thoughtful.

### 4.2 Magazine

Magazine is an editorial-style layout project that leans heavily on typography, column structure, and attention to reading flow. It is designed to feel like a real publication page rather than a generic web layout.

What I learned here was how much tone is carried by typography and spacing alone. It also improved my understanding of how to lead a reader through content using contrast, rhythm, and hierarchy.

### 5.1 Ferris Wheel

Ferris Wheel is a more animated or visually dynamic CSS project that recreates a fairground wheel. It emphasizes transforms, circular motion, and structured visual components that fit together as one moving object.

I learned how animation and transforms can give a page a sense of life without relying on complex assets. The project also helped me think about motion as part of design rather than decoration.

### 5.2 Penguin

Penguin is another CSS illustration project, but with more character-based shape building. It uses circles, curves, and layered body parts to form a recognizable figure from primitive shapes.

What I learned was how many familiar objects can be recreated using basic CSS geometry. It also strengthened my understanding of pseudo-elements and relative positioning as creative tools.

### 6.1 Calorie

Calorie introduces JavaScript into the workflow by dealing with nutritional or numeric information. It likely focuses on calculations, display updates, or user-driven conversions related to calorie data.

I learned how to connect input data to a meaningful output instead of just rendering static content. The project also helped me practice logic that feels practical and easy to explain.

### 6.2 Stone Paper Scissors

This is a playable game project built around rock-paper-scissors mechanics. It uses random outcomes, user choices, and win-loss comparisons to create a simple but engaging interaction loop.

What I learned here was how to structure game logic cleanly and how to represent state in a way that users can follow. It also taught me the importance of immediate feedback in making a game feel responsive.

### 6.3 Palindrome

Palindrome checks whether a word or phrase reads the same in both directions. The project is centered around string manipulation, comparison logic, and clear result output.

I learned how to work with text in a more algorithmic way. It also showed me that even small utility projects can be powerful when they solve one problem well.

### 7.1 Date Formatter

Date Formatter converts raw date data into something readable and user-friendly. The main purpose is to make time information easier to understand across different formats.

What I learned was how format conversion can improve usability immediately. It also helped me get more comfortable handling built-in date behavior and turning it into clean UI text.

### 7.2 Kabaddi Cards

Kabaddi Cards is a themed content project that presents information in card form. It likely groups player or match-style data in a layout that feels organized and visually consistent.

I learned how cards can help structure information into digestible pieces. It also reinforced how theming can make even a simple layout feel more energetic and distinctive.

### 7.3 To Do List

To Do List is a classic productivity app project where users create, view, and manage tasks. Its core value is interaction: adding tasks, updating them, and keeping the list useful over time.

I learned how state management affects every part of a small app. It also helped me see why clear task flows and instant UI updates matter in everyday utility tools.

### 7.4 Int to Binary

Int to Binary converts decimal integers into binary form. The project is algorithmic at its core and is mainly about transformation logic and correct output formatting.

What I learned was how number systems work and how to translate them into code. It also strengthened my comfort with step-by-step logic that has to stay exact.

### 7.5 Roman Converter

Roman Converter translates numbers into Roman numerals or performs the reverse conversion. The project relies on branching rules, ordered mapping, and formatted results.

I learned how conversion problems often need structured lookup rules more than heavy computation. It also taught me how to think about edge cases and special numeral patterns carefully.

### 8.1 Spam Checker

Spam Checker evaluates text for suspicious patterns or rule-based indicators. It works like a lightweight classifier that decides whether the message looks harmless or not.

I learned how pattern detection can be built from simple logic rules. It also showed me how validation tools can be useful beyond forms and can help interpret content in a practical way.

### 8.2 Number Sorter

Number Sorter organizes a list of values into a chosen order. The main task is to compare entries correctly and return a sorted list that the user can trust.

What I learned here was how sorting depends on comparison strategy and data type handling. It also improved my appreciation for array processing and clean result presentation.

### 8.3 Statistics Calculator

Statistics Calculator computes summary values such as averages or spread metrics. It turns raw data into a more meaningful set of numbers that describe the input.

I learned how to build small analytical tools that do real work. The project also helped me understand how mathematical output becomes more useful when it is grouped and labeled clearly.

### 8.4 Spreadsheet

Spreadsheet is a grid-based project that mimics cell editing or table-style data behavior. It is useful for practicing large, structured layouts and dynamic updates across many small units.

I learned how grid systems scale when the interface becomes data-heavy. It also taught me how a spreadsheet mindset depends on clarity, consistency, and predictable interaction.

### 8.5 Telephone Validator

Telephone Validator checks whether a phone number matches a valid pattern. It is a classic validation project that usually relies on regular expressions or structured rule checks.

### 9.1 Shopping Cart
